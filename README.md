## 📖 پایا‌یار چیست؟

**پایا‌یار** یک نرم‌افزار دسکتاپ (ویندوز) و موبایل (اندروید) است که با هدف ایجاد یک **سیستم‌عامل شخصی برای مطالعه** طراحی شده است. این پروژه برای دانش‌آموزان کنکوری ساخته شده که به دنبال یک ابزار جدی، سریع، آرام و کاملاً قابل اعتماد برای مدیریت زمان، انرژی و داده‌های درسی خود هستند.

برخلاف اکثر اپلیکیشن‌های مشابه که داده‌های شما را به سرورهای خود می‌فرستند، **پایا‌یار فلسفه Local-first را به صورت رادیکال دنبال می‌کند**:
- داده‌های شما فقط روی دستگاه خودتان (SQLite) ذخیره می‌شود.
- نیازی به اینترنت برای کارهای روزمره ندارید.
- هیچ‌گونه Telemetry، Analytics یا ردیابی در کد وجود ندارد.
- حساب کاربری وجود ندارد. شما صاحب کلیدها و داده‌هایتان هستید.

> **اصل طلایی محصول:** `Plan → Execute → Record → Analyze → Improve`
> (برنامه‌ریزی کن ← اجرا کن ← ثبت کن ← تحلیل کن ← بهبود بده)

## 🚀 امکانات و قابلیت‌های کلیدی

پایا‌یار به هشت ماژول مستقل اما کاملاً به هم پیوسته تقسیم شده است:

### ۱. 🏠 خانه (Home / Command Center)
- نمایش خلاصه وضعیت امروز (ساعت مطالعه، تعداد تست، درصد پیشرفت).
- تقویم شمسی یکپارچه.
- تایم‌لاین عمودی برنامه امروز.
- نمایش آخرین فعالیت‌ها و آزمون‌ها.
- کارت اختصاصی «مشاور AI» برای دریافت تحلیل لحظه‌ای.

### ۲. 📅 برنامه‌ریزی (Planning)
- **سطوح برنامه‌ریزی:** نقشه راه (Roadmap)، برنامه راهبردی، چرخه آزمون (دو هفته‌ای)، برنامه هفتگی و برنامه ۲۴ ساعته روزانه.
- **برنامه هفتگی:** ۷ بلوک جداگانه برای شنبه تا جمعه با قابلیت Drag & Drop (کشیدن و رها کردن) تسک‌ها بین روزها.
- **برنامه روزانه:** تایم‌لاین دقیق با امکان تیک زدن و مشاهده زمان باقی‌مانده.
- تفکیک کامل داده‌های «برنامه‌ریزی‌شده» (Planned) از «عملکرد واقعی» (Actual).

### ۳. 📚 مطالعه (Study)
- ثبت جلسات مطالعه روزانه با جزئیات کامل (درس، مبحث، مدت زمان).
- ثبت نتایج تست‌ها (تعداد صحیح، غلط، نزده).
- **تایمر تمرکز (Pomodoro):** ثبت خودکار جلسه مطالعه پس از اتمام تایمر.
- یادداشت‌گذاری سریع برای هر جلسه.

### ۴. 📝 آزمون‌ها (Exams)
- ثبت آزمون‌های آزمایشی و کنکورهای سراسری.
- ثبت نتایج به تفکیک دروس و مباحث.
- محاسبه درصدها و رتبه‌های تخمینی.
- تحلیل روند عملکرد در طول زمان.

### ۵. 📊 گزارش‌ها (Reports)
- نمودارهای خطی و میله‌ای برای ساعت مطالعه، تعداد تست، خواب و ورزش.
- مقایسه عملکرد هفتگی و ماهانه.
- نمایش درصد انجام کارها به صورت نمودار دایره‌ای.
- تمام محاسبات به صورت محلی از SQLite انجام می‌شود.

### ۶. 🌱 سبک زندگی (Lifestyle)
- ثبت شاخص‌های روزانه: خواب، تغذیه، ورزش، حال روز، انرژی و استفاده از موبایل.
- مشاهده وضعیت به صورت Ring Chart (نمودار حلقه‌ای).
- رنگ‌های معنادار (سبز: خوب، نارنجی: متوسط، قرمز: ضعیف).
- گزارش ماهانه خواب و ورزش.

### ۷. 🤖 مشاور هوش مصنوعی (AI Advisor)
- چت با مدل Gemini (یا سایر مدل‌ها با کلید کاربر).
- **طراحی امن:** AI فقط پیشنهاد می‌دهد. هیچ تغییری در برنامه بدون تأیید صریح کاربر اعمال نمی‌شود (Approval Flow).
- دریافت پیشنهاد برای بهبود برنامه هفتگی، تحلیل آزمون‌ها و خلاصه‌سازی متن.

### ۸. ⚙️ تنظیمات (Settings)
- تم تاریک و روشن (Dark/Light Mode).
- شش پالت رنگی مختلف (آبی، بنفش، سبز، نارنجی، خاکستری، آبی روشن).
- تغییر زبان (فارسی / انگلیسی).
- مدیریت کلیدهای API.
- پشتیبان‌گیری (Export/Import) به صورت JSON.

## 🛠 معماری فنی و تکنولوژی‌ها

پایا‌یار با استفاده از تکنولوژی‌های مدرن و با رعایت اصول Clean Architecture توسعه یافته است.

| لایه | تکنولوژی |
| :--- | :--- |
| **Frontend** | Flutter 3.47.6 · Dart 3.13.5 |
| **State Management** | Riverpod |
| **Database** | SQLite (به همراه Drift ORM) |
| **AI** | Gemini API (کلید اختصاصی کاربر) |
| **Typography** | فونت شبنم (Shabnam) |
| **Icons** | Phosphor Icons |

### ساختار پوشه‌ها (High-Level)
```text
lib/
├── core/          # تنظیمات پایه، تم، مسیریابی
├── data/          # مدل‌ها، دیتابیس (Drift)، ریپازیتوری‌ها
├── features/      # ماژول‌های اصلی (Home, Planning, Study, ...)
├── shared/        # ویجت‌ها و کامپوننت‌های مشترک
└── main.dart      # نقطه ورود برنامه
